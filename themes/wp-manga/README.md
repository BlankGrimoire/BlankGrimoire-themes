# `theme.wp-manga`

Declarative adapter for a reusable WordPress content-theme structure.

The package contains only synthetic fixtures and does not target individual
websites. It supports search, details, chapters, attribution, and reader page
images through the BlankGrimoire SDK runtime.

## Development

From the repository root:

```bash
pnpm --filter @blankgrimoire/theme-wp-manga test
pnpm --filter @blankgrimoire/theme-wp-manga build
pnpm --filter @blankgrimoire/theme-wp-manga manifest
```
