# `theme.themesia`

Declarative adapter for a reusable Themesia-family theme structure.

The package contains only synthetic fixtures and does not target individual
websites. It supports catalog metadata and reader pages from an inline JSON
payload through the BlankGrimoire SDK runtime.

## Development

From the repository root:

```bash
pnpm --filter @blankgrimoire/theme-themesia test
pnpm --filter @blankgrimoire/theme-themesia build
pnpm --filter @blankgrimoire/theme-themesia manifest
```
